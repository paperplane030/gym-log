# 功能說明

Gym Log 用來記錄每次重量訓練的動作、重量、次數。主要在 iPhone 上使用（加入主畫面），資料會自動備份到雲端，也可以匯出到 Excel 分析。

技術細節請看 [TECHNICAL.md](./TECHNICAL.md)。

---

## 畫面總覽

底部導覽列有五個分頁：

| 分頁 | 用途 |
|---|---|
| **訓練** | 記錄今天的訓練 |
| **紀錄** | 瀏覽、修改過去的訓練 |
| **範本** | 管理課表範本 |
| **動作** | 管理動作庫 |
| **設定** | 外觀、同步、匯出匯入、帳號 |

右上角的圓點是同步狀態，點一下會立即同步：

| 顏色 | 狀態 |
|---|---|
| 🟢 綠 | 已同步 |
| 🟡 黃（閃爍） | 同步中 |
| 🔴 紅 | 同步失敗，到設定頁看錯誤訊息 |
| ⚪ 灰 | 離線，資料先存在手機，恢復網路後自動上傳 |

---

## 1. 登入

- 使用 **Google 帳號**登入。
- 第一次登入時，會自動建立 7 個類別（胸、背、腿、肩、手臂、核心、其他）和 23 個常見動作（臥推、深蹲、硬舉等），之後都可以自由修改或刪除。

---

## 2. 訓練（今日訓練）

### 開始訓練
今天還沒有紀錄時，有兩種開始方式：
- **開始空白訓練**：從零開始，自己加入動作。
- **從範本開始**：選一個範本，會依範本的動作順序和目標組數，先建好空白的組。

今天已經有紀錄時，會直接顯示這次訓練。

### 訓練資訊
- **日期**：預設是今天，可以修改（例如補記昨天的訓練）。改成其他日期後，這次訓練會移到「紀錄」頁。
- **訓練備註**：整次訓練的備註，例如「今天狀況不好」。
- 從範本開始的訓練，日期旁邊會顯示範本名稱。

### 動作
- **＋ 加入動作**：打開動作選單，可以搜尋、依類別篩選。搜尋不到的話，可以直接新增，新動作會放在目前選的類別。
- 動作右上角的 **⋯**：上移、下移、移除這個動作（會刪除它的所有組）。

### 記錄每一組

```
⠿  1   [ 60   ]  [ 8 ]   ✎  ✕
       上次 60kg × 8 · 套用
```

| 元素 | 說明 |
|---|---|
| ⠿ | 按住拖曳，調整這組的順序，組號會自動重排 |
| 數字 | 組號 |
| 重量 | 單位 kg，可以有小數（例如 62.5）。自體重量的動作可以留空 |
| 次數 | 整數 |
| ✎ | 展開這一組的備註欄；有備註時會變綠色 |
| ✕ | 刪除這一組，後面的組號會自動往前補 |
| **＋ 新增一組** | 在最後新增一組空白的組 |

- 輸入框點下去會**全選**，可以直接打新的數字覆蓋。
- 離開輸入框時自動存檔，不需要按儲存。
- 新增的組**不會自動帶入數字**，要自己填，或點下方的「套用」。

### 參考資訊
參考資訊只會顯示在畫面上，**不會自動填進輸入框**：

| 顯示位置 | 內容 | 顏色 |
|---|---|---|
| 動作名稱下方 | 範本設定的目標，例如「目標 4 組 × 8 下 · 60kg」 | 藍 |
| 動作名稱下方 | 上次做這個動作的完整紀錄，例如「上次 11/9（一）：60kg × 8、62.5kg × 6」 | 灰 |
| 每一組下方 | 上次同一組的數字，例如「上次 60kg × 8 · 套用」，**點一下才會填入** | 灰 |

「上次」指的是這次訓練日期當天或之前，最近一次有做這個動作的訓練。只會參考有填次數的組。

### 刪除訓練
頁面最下方的 **刪除這次訓練**。

## 3. 紀錄

- 依月份列出所有訓練，新的在上面。
- 每筆顯示：日期、使用的範本、做了哪些動作、完成幾組（有填次數的組）、訓練備註。
- 點進去可以修改，功能和「訓練」頁一樣。

---

## 4. 範本

把常練的動作組合存成範本，例如「推日」「拉日」「腿日」，訓練時一鍵帶入。

### 範本列表
- 右下角 **＋**：輸入名稱，建立新範本。
- 每個範本會顯示動作數量和動作清單，點進去可以編輯。

### 編輯範本
| 欄位 | 說明 |
|---|---|
| 名稱 | 範本名稱 |
| 備註 | 選填 |
| 動作 | 每個動作可以設定目標**組數**、**次數**、**重量**（重量可以留空） |

- **＋ 加入動作**：從動作庫選擇。新加入的動作預設 3 組。
- ⠿：拖曳調整動作順序。
- ✕：從範本移除這個動作。
- **複製範本**：複製一份，適合做類似的課表。
- **刪除範本**：已經記錄的訓練不受影響。

### 範本和訓練的關係
- 從範本開始訓練時，是**複製**一份動作清單到這次訓練。在訓練中增減動作或組數，**不會改到範本**。
- 之後修改範本，會影響用這個範本的訓練所顯示的「目標」，但不會改到已經記錄的數字。

---

## 5. 動作

- 依類別分組列出所有動作，上方可以依類別篩選。
- 右下角 **＋** 新增動作；點動作可以修改名稱、類別、備註，或刪除。
- 刪除動作後，**過去的紀錄會保留**，紀錄中仍然會顯示動作名稱。

### 管理類別
點右上角的 **管理類別**。類別分成兩種：

| | 預設類別 | 自訂類別 |
|---|---|---|
| 項目 | 胸、背、腿、肩、手臂、核心、其他（有「預設」標籤） | 自己新增的，例如「有氧」「伸展」 |
| 排序 | 按住 ⠿ 拖曳 | 按住 ⠿ 拖曳 |
| 改名 | ❌ | 直接點名稱修改，離開輸入框就會存檔 |
| 刪除 | ❌ | 按 ✕。**動作不會被刪除**，會變成「未分類」 |

- **新增**：在下方輸入名稱，按 **新增**。名稱不能重複。
- 排序會套用到動作頁和動作選單的類別順序。
- 有「未分類」的動作時，篩選列最後會多一個「未分類」。

## 6. 設定

### 外觀
跟隨系統／淺色／深色，三選一。

### 同步
- 顯示上次同步時間。
- 同步失敗時會顯示錯誤訊息。
- **立即同步**：手動觸發同步。

平常不需要手動同步，以下時機會自動同步：登入後、App 切回前景、網路恢復、匯入資料後。

### 匯出
每一組一列，欄位如下：

| 日期 | 動作 | 部位 | 組 | 重量 | 單位 | 次數 | 備註 | 訓練備註 |
|---|---|---|---|---|---|---|---|---|
| 2026-11-10 | 槓鈴臥推 | 胸 | 1 | 60 | kg | 8 | | 狀況不錯 |
| 2026-11-10 | 槓鈴臥推 | 胸 | 2 | 62.5 | kg | 6 | 最後一下勉強 | 狀況不錯 |

- **複製（貼到 Excel）**：複製到剪貼簿，貼到 Excel 或 Google 試算表會自動分欄。
- **下載 CSV**：下載 `gym-log-日期.csv`，用 Excel 打開中文不會亂碼。
- 只會匯出有填重量或次數的組。

### 匯入
1. 點 **匯入紀錄**。
2. 用以下任一方式放入資料：
   - **從剪貼簿貼上**：在 Excel 選取範圍複製後，按這個按鈕
   - **選擇檔案**：CSV 或 TSV 檔
   - 直接貼到輸入框
3. 按 **檢查資料**，會顯示預覽：
   - 會匯入幾次訓練、幾組
   - 會新增哪些動作（動作庫裡沒有的）
   - 有問題的資料列和原因，例如日期格式錯誤（這些列會被略過）
4. 本機已經有紀錄的日期，預設會**略過**，避免重複匯入。取消勾選就會一起匯入。
5. 按 **確認匯入**。

匯入格式的規則：
- 欄位順序同匯出。有標題列的話，會依標題名稱對應欄位，順序可以不同。
- 日期可以寫 `2026-11-10` 或 `2026/11/10`。
- 部位、單位、組、備註可以留空。單位空白當成 kg，組號空白會自動編號。
- 「部位」填的是類別名稱，只對**新動作**有作用：不存在的類別會自動建立（預覽時會列出），空白則是未分類。已經在動作庫裡的動作，維持原本的類別。
- 同一天的資料會合併成一次訓練。

### 帳號
顯示登入的 Email，以及 **登出** 按鈕。登出前會先同步，然後清除這台裝置上的資料。雲端資料不受影響，再次登入就會下載回來。

---

## 離線使用

- 健身房收訊不好也能正常記錄，資料先存在手機裡。
- 恢復網路、或下次打開 App 時會自動上傳。
- 加入主畫面後，沒有網路也能打開 App。
